# Aside 云同步与备份

顶部「云同步」和设置页均可打开统一的「云同步与备份」面板，复用 `shared/cloud-sync-ui.js`。同步服务地址预填且可修改，密钥默认隐藏，可显示或复制。JSON 完整备份、备份恢复、本月/全部 Markdown 导出都集中在该面板，设置页不再重复提供导入导出。

## 数据和图片

文字、标签关键词、置顶、回复、高亮等记录属性沿用现有独立 Worker `aside-sync` 和 D1 数据库 `daylog`，保留历史数据与原密钥。新增私有 R2 桶 `aside-images`，通过同一个 Worker 的带鉴权接口上传/下载 JPEG、PNG、WebP（单张最多 5 MB）。R2 桶不开放公开访问。服务地址不是密钥；实际密钥只在浏览器本机和 Cloudflare Secret 中保存，不写入公开代码或备份。

本地保存后后台自动同步，离线可继续记录。原图仍保存在 IndexedDB，首次同步会自动补传当前记录引用的本机图片；其他设备打开记录时下载并缓存，之后可离线查看。旧版只同步了图片编号，旧图片必须在仍有原图的设备打开新版并联网同步，随后其他设备才能下载。尚未补传时显示占位，不丢弃图片引用，后续同步会自动重试读取。

上传按原图编号和内容校验，重复上传幂等，不允许用不同内容替换同一编号的原图。图片下载和同步 API 不走 Service Worker 静态缓存。删除记录保留墓碑，旧设备不能重新上传同一 ID 恢复已删除内容；未再引用的云端图片保留，不自动清空，以免破坏其他设备或备份。

同步失败保留本机内容，联网、回到前台和页面停留时会自动重试。新设备的默认标签不会覆盖云端已有关键词，独立新增标签会合并；首次从个性化设备连接时，其自定义标签可替代空白设备的默认种子。后续标签整体修改以最后写入为准。每条记录按 ID 合并，更新内容采用后保存的版本；同名但独立创建的记录分别保留。正在编辑或请求期间新保存的内容不会被后台响应覆盖。

完整 JSON 备份包括文字、标签和所有引用图片。如果部分原图尚未补传/无法取得，会提示备份未完成，避免生成缺图却声称完整的文件。JSON 导入按 ID 合并，不覆盖已有记录和关键词，导入图片在入库后补传。Markdown 用于阅读和 Obsidian，图片仍以文字占位表示，不能作为完整恢复备份。

## 部署与兼容

可公开的 Worker 源码位于 `cloud-worker/worker.js`，结构模板在 `cloud-worker/schema.sql` 和 `wrangler.example.toml`。本机既有 `sync-worker/` 整个目录继续被仓库忽略，包含真实部署配置和凭据；不要强制加入 Git。实际配置沿用既有 D1 ID，入口指向 `../cloud-worker/worker.js`，新增 R2 的 `IMAGES` 绑定。已有数据库不重建、不重跑创建脚本。

`SYNC_KEY` 保留既有密钥；可选 `SYNC_KEY_V2` 为新设备提供另一把专用密钥，两者访问同一本个人记录。新增设备可在面板复制已保存的密钥，不能填写 Cloudflare 登录密码或 API Token。云端不提供端到端加密。

同步接口兼容旧客户端，增量游标采用与 D1 事务一起递增的时序值，避免并发/同毫秒写入漏读，分页不拆开同一版本。Service Worker 仅更新 `aside-` 缓存，缓存页面、图标、共享面板和图片客户端脚本；不清 localStorage，不缓存鉴权 API。

## 验证

```sh
node --test aside/tests/*.test.mjs
```

使用内存 SQLite 和模拟 R2，覆盖双设备、离线、标签保护、删除墓碑、请求期间的保存、配置切换、同毫秒游标、鉴权、图片原图不被替换、上传重试、下载和离线读图，以及完整备份缺图拦截和缓存隔离。

`tests/browser.py` 针对可丢弃的本地 Worker，使用 `127.0.0.1:8000` 与 `localhost:8000` 两个独立存储环境。先通过独立临时 Wrangler 配置，绑定可丢弃本地 D1/R2，在 `.dev.vars` 设置 `SYNC_KEY="aside-browser-test-key-123456789"`，对本地库应用 `cloud-worker/schema.sql`，启动 `wrangler dev --local --ip 127.0.0.1 --port 8793 --persist-to <临时目录> --config <临时配置>`。启动 web-access CDP Proxy 后，在仓库根目录运行 `python3 aside/tests/browser.py`。测试自行启动静态服务，不访问生产同步接口，结束后关闭自行创建的浏览器页签。
